# umami

> Documentation for Umami, an open-source web and product analytics platform.

## Documentation

- [Introduction](/docs.md): An overview of Umami v3, the open-source web and product analytics platform, with its main features and how to get started on Cloud or self-hosted.
- [Installation](/docs/install.md): Install a self-hosted Umami instance from source, with Docker Compose, from a prebuilt Docker image, or on Kubernetes with a third-party Helm chart.
- [Getting updates](/docs/updates.md): Update a self-hosted Umami installation from source or with Docker, and refresh PostgreSQL statistics after a major upgrade.
- [FAQ](/docs/faq.md): Answers to common questions about Umami, including GDPR compliance, cookies, collected data, self-hosting, supported databases, and data retention.
- [Login](/docs/login.md): Log in to Umami with the default admin account, change the default password, and enable two-factor authentication for extra protection.
- [Add a website](/docs/add-a-website.md): Add a website to Umami by entering its name and domain, so you can start tracking its traffic in your dashboard.
- [Collect data](/docs/collect-data.md): Copy your website's tracking code from Umami, add it to your site's head section, and troubleshoot data that does not appear.
- [Enable Share URL](/docs/enable-share-url.md): Generate a public Share URL for a website in Umami and choose which traffic, behavior, and growth views are visible to others.
- [Environment variables](/docs/environment-variables.md): Reference for the runtime and build time environment variables you can set to configure a self-hosted Umami installation.
- [Enable Cloudflare headers](/docs/enable-cloudflare-headers.md): Configure Cloudflare and your reverse proxy to pass visitor location headers to Umami so it can record region and city data.
- [Use Google Tag Manager](/docs/google-tag-manager.md): Install the Umami tracker with a Google Tag Manager Custom HTML tag that creates the script element and keeps its data-website-id attribute.
- [Enable Redis](/docs/enable-redis.md): Enable Redis in self-hosted Umami with the REDIS_URL variable to cache lookups, reduce database load, and handle login sessions.

- [Bypass ad blockers](/docs/bypass-ad-blockers.md): Keep ad blockers from blocking Umami by proxying the tracker and collection endpoint, self-hosting the script, or renaming them.
- [Exclude my own visits](/docs/exclude-my-own-visits.md): Stop your own visits from appearing in Umami stats by setting a localStorage flag in your browser for each website you track.
- [Tracker functions](/docs/tracker-functions.md): Use the umami.track() and umami.identify() tracker functions to send pageviews, events, event data, and session data from your own code.
- [Tracker configuration](/docs/tracker-configuration.md): Configure the Umami tracker script with data attributes for the host URL, auto-tracking, domains, tags, performance, privacy, and a before-send hook.
- [Track events](/docs/track-events.md): Track custom events in Umami with data attributes on HTML elements or with JavaScript, then view the events and their properties.
- [Distinct IDs](/docs/distinct-ids.md): Set a Distinct ID with umami.identify() or the Sending stats API to link a user's sessions and activity across visits and devices.
- [Tags](/docs/tags.md): Add the data-tag attribute to the Umami tracker script to group events under a tag for A/B testing, then filter your website data by tag.
- [Links](/docs/links.md): Create short tracking links in Umami that redirect to a destination URL and record clicks, with optional social preview and UTM parameters.
- [Pixels](/docs/pixels.md): Create Umami tracking pixels to record views in HTML emails and on external pages where JavaScript is not supported, and edit or delete them.
- [Event data](/docs/event-data.md): Attach custom properties to tracked events in Umami with data attributes or umami.track(), then view them on the Events page.
- [Annotations](/docs/annotations.md): Pin dated notes to a website's traffic chart in Umami to record deploys, campaigns, or outages, then drill into those dates.
- [Filters](/docs/filters.md): Filter Umami reports by URL, source, location, environment, UTM, and custom properties, and combine conditions with match modes and operators.
- [Segments](/docs/segments.md): Save commonly used filters as segments in Umami so you can quickly reapply them, and add, apply, edit, or delete segments.
- [Cohorts](/docs/cohorts.md): Create cohorts in Umami to group users who visited a URL or triggered an event within a date range, then apply them as filters.
- [Sessions](/docs/sessions.md): View visitor sessions in Umami, open individual visitor profiles, and explore and filter the custom session properties you have saved.
- [Replays](/docs/replays.md): Enable session replays in Umami, add the recorder script to your website, and watch and save recordings of real visitor sessions.
- [Heatmaps](/docs/heatmaps.md): Enable heatmaps in Umami to see where visitors click and how far they scroll on each page, grouped by screen width over a live page preview.
- [Performance](/docs/performance.md): Collect real-user Core Web Vitals with the Umami tracker and review LCP, INP, CLS, FCP, and TTFB by page, device, and browser.
- [Compare](/docs/compare.md): Use the Umami Compare insight to compare website stats and metrics against the previous period or the same period last year.
- [Breakdown](/docs/breakdown.md): Use the Umami Breakdown insight to segment visitors, visits, views, bounce rate, and visit duration by the fields and filters you choose.
- [Goals](/docs/goals.md): Create a goal in Umami to track the conversion rate of visitors who view a specific page or trigger a specific event within a date range.
- [Funnel](/docs/funnel.md): Create a funnel report in Umami to see how many visitors complete a sequence of page visits or events, and where they drop off between steps.
- [Journey](/docs/journey.md): Create a journey report in Umami to see the most common paths visitors take through your website, from where they start to where they drop off.
- [Retention](/docs/retention.md): Use the Umami Retention insight to see how many visitors return on the days after their first visit, shown as a daily cohort chart.
- [UTM](/docs/utm.md): Use the Umami UTM insight to see views broken down by the five standard UTM parameters and measure how your marketing campaigns perform.
- [Revenue](/docs/revenue.md): Track revenue in Umami by sending revenue and currency event data with tracker functions or data attributes, then run the Revenue insight.
- [Attribution](/docs/attribution.md): Use the Umami Attribution insight to see which referrers, paid ads, and UTM campaigns led to a page view or event, using first-click or last-click models.
- [Insights](/docs/insights.md): An overview of the insight reports built into Umami, including compare, breakdown, funnel, retention, UTM, goals, journey, revenue, and attribution.
- [Using boards](/docs/using-boards.md): Learn the Umami board types and how to view boards, customizable dashboards that combine widgets from websites, pixels, and links.
- [Add a board](/docs/add-a-board.md): Create, edit, clone, delete, and share boards in Umami to build custom dashboards for websites, pixels, and links.
- [Design a board](/docs/design-a-board.md): Use design mode in Umami to add rows and columns to a board, place traffic, event, and revenue components, and resize the layout.
- [Using teams](/docs/using-teams.md): Understand Umami team roles and permissions, and open a team from the Teams page or the quick team access dropdown in the sidebar.
- [Add a team](/docs/add-a-team.md): Create a team in Umami from the Settings page to organize users and share websites, with yourself added as the team owner.
- [Join a team](/docs/join-a-team.md): Share a team's access code with other users, regenerate the code, and join an existing Umami team by entering an access code.
- [Manage a team](/docs/manage-a-team.md): Add websites to a team, edit or remove team members as the team owner, and transfer websites between your account and a team you own.
- [Add a user](/docs/add-a-user.md): Create separate Umami user accounts from the Admin console, choose a role for each user, and require two-factor authentication.
- [Metric definitions](/docs/metric-definitions.md): Definitions of the default metrics Umami collects, including event, session, location, UTM, ad click ID, Web Vitals, and calculated metrics.
- [Integrations](/docs/integrations.md): A list of community plugins, API clients, and libraries for using Umami with frameworks and platforms such as WordPress, Nuxt, Gatsby, and Flutter.
- [MCP](/docs/mcp.md): Connect Claude, ChatGPT, Cursor, and other AI tools to your Umami analytics with the official Model Context Protocol server, on Umami Cloud or a self-hosted instance.
- [Contributing](/docs/contributing.md): Contribute code to Umami by branching from dev, opening pull requests against dev, and following the guidelines for reporting issues.
